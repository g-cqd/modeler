# modeler 0.2.0 (from 0.1.1)

Wave 1 of the analyzer release train (analyzerkit tag `analyzerkit-wave-1`): modeler on analyzerkit's shared
foundations. `check` follows each method's control flow (analyzerkit 0026). The TLA+, `classes`, `states` and
`facts` outputs are unchanged.

## Flags

- `check` added: `--format` (xcode, json, sarif), `--config`, `--baseline`, `--write-baseline`, `--only`,
  `--only-from`, `--relative-to`, `--report-new-since`, `--rules`, `--exclude-path`, `--include-regions`,

  `defines`, only the `#if` clauses active under those conditions are modelled (analyzerkit 0059, ADR-0029).
  Without one every clause is modelled, as before.

- New subcommands: `rules [id]` and `explain`.

- Removed: none.

## Exit codes

- `check` follows ADR-0018: findings are warnings unless the configuration says otherwise, so they fail a run only
  with `--strict` or an `error` severity.
- A missing path or no Swift file exits 64, and a run that read nothing 70.

## Report

- `check --format json` is new: the shared envelope (`schemaVersion` 1, `tool`, `version`, `findings`,
  `runNotes`, `skippedFiles`, `timings`). SARIF uses `modeler/v1` fingerprints.
- A finding of the new kind `claimedAwait` carries `claimLine` and `writers` in `modeler facts`' `reentrancy`
  list. Absent keys elsewhere; `facts` keeps `schemaVersion` 1.

## Configuration

- `defines` and `platforms` (shared keys) are read: with a define, only the active `#if` clauses are modelled, and
  they are part of the cache salt.
- `.modeler.json`, or a `modeler` section of `.swift-analyzers.json`: `disable`, `severity`, `exclude`,
  `includeRegions`, `excludeRegions`. Unknown or repeated keys exit 78.
- Suppression comments: `// @modeler:accept reentrancy -- reason` (or `@md:`).

## Cache

`--cache-path` names a root directory now (ADR-0011): facts sit in sharded files under `<root>/facts/<workspace>/`, keyed by file metadata then content, and memory-mapped. Payloads are protobuf. A tool keeps 512 MiB at most and evicts the least recently used workspaces first. A v1 cache file at the same path is replaced. The default root is `~/Library/Caches/<tool>` on macOS and `$XDG_CACHE_HOME/<tool>` (or `~/.cache/<tool>`) on Linux. On a CI runner, delete the old v1 cache files once; the tool would replace them anyway.

## Findings that may appear

- Only with `--define` or `defines`: findings in the clauses those conditions make active, and none from the
  others. Without a define nothing changes.
- `reentrancy` on a path source order missed: a write the loop carries past a check and an `await` (probe M2), or a
  write on a path that a first write no longer hides (a `catch`, a branch that returns). maintastic: 2 new, plus a
  second write after one claim.
- `reentrancy` (claimed): a check, a write that claims the member, an `await`, then a write, when another method of
  the type writes the member. The message names those methods (probe M1).

## Findings that may disappear

- `reentrancy` or `lock-gap` pairing a check and a write on exclusive branches (probe M3; one on maintastic).
- `reentrancy` after a claim when no other method writes the member (probe M1; one on maintastic).
- Findings in `Package.swift` manifests and build-phase scripts, which are the `script` region now.
- A `reentrancy` finding whose `await` was on another branch now names the `await` on the write's own path; its
  fingerprint is unchanged.
