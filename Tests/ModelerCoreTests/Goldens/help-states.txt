OVERVIEW: Mermaid state diagrams of every enum-valued member the code assigns.

USAGE: modeler states [<paths> ...] [--include-tests] [--no-cache] [--cache-path <cache-path>] [--type <type> ...] [--output <output>]

ARGUMENTS:
  <paths>                 Files or directories to read (default: the current
                          directory). (default: .)

OPTIONS:
  --include-tests         Model test and generated code too.
  --no-cache              Do not read or write the facts cache.
  --cache-path <cache-path>
                          The facts cache file (default: a per-workspace file
                          under the user cache directory).
  --type <type>           Only machines whose owner or enum is this type;
                          repeatable.
  --output <output>       Write one .mmd file per machine into this directory
                          instead of printing.
  --version               Show the version.
  -h, --help              Show help information.
